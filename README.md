# Los Guardianes del Tablero

SITE académico desarrollado en HTML5, CSS3 y JavaScript para presentar la experiencia de aprendizaje con gamificación inmersiva **Los Guardianes del Tablero**.

## Estructura

- `index.html`: página principal del SITE.
- `assets/css/styles.css`: estilos visuales y diseño responsivo.
- `assets/js/main.js`: interacciones, filtros, navegación y tablero de ajedrez.
- `assets/img/`: recursos gráficos del proyecto.
- `data/videos.json`: listado de videos de apoyo usados como referencia.

## Publicación en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos conservando la misma estructura de carpetas.
3. Entra a **Settings > Pages**.
4. En **Source**, selecciona la rama principal y el directorio principal del proyecto.
5. Guarda los cambios y espera a que GitHub genere el enlace público.

## Contenido

El SITE incluye diagnóstico, objetivo, narrativa, roles, gamificación, misiones, videos de apoyo, tablero interactivo de ajedrez, evaluación, recursos y referencias.
